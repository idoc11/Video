# Движок роликов

Общий код для вертикальных роликов 1080×1920 «история по дням»: персонаж, HUD «ДЕНЬ N» со шкалой,
подписи с подсветкой слов, переходы, камера, рекламный баннер, музыка и звуковые эффекты.

Ролик = папка с двумя файлами:
- `script.json` — реплики диктора с режиссурой (темп `ls`, высота `pitch`, размах интонации `range`,
  эффект `fx`: echo / memory / reverb / air / radio, второй голос `speaker`, пауза `gap`), подписи,
  день и шкала, какие картинки показывать и какие звуки (`sfx`), блок `banner`;
- `views.js` — картинки сцен (SVG-функции, рисуют кадр по времени).

Сборка: `engine/build.sh <папка ролика>` → `<папка>/<output>.mp4`.

Озвучка: Piper (голоса dmitri / denis / irina), интонация растягивается через Praat,
каждая реплика озвучивается до 5 раз — остаётся самый разборчивый дубль (проверка распознаванием речи).
Зависимости: `pip install piper-tts praat-parselmouth sherpa-onnx numpy`, Node + Playwright, ffmpeg.
