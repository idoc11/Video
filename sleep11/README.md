# «Он не спал 11 дней» — демо-ролик для Shorts/TikTok/Reels

Вертикальное видео 1080×1920, 21 сек. Всё генерируется кодом: графика, озвучка, музыка, эффекты.

| Файл | Что делает |
|---|---|
| `script.json` | сценарий: реплики диктора, подписи (`[слово]` — жёлтое, `{слово}` — красное), день, шкала усталости, какие картинки в сцене |
| `tts.py` | озвучка голосом Piper (dmitri), строит таймлайн по длительности реплик |
| `scene.html` | вся графика на SVG: персонаж, мозг, сцены, HUD «ДЕНЬ N», подписи, переходы |
| `render.js` | снимает кадры через Chromium (Playwright), 30 к/с |
| `audio.py` | синтез музыки и звуковых эффектов, сведение с голосом |
| `build.sh` | сборка целиком → `sleep11_demo.mp4` |

Сборка: `./build.sh` (озвучка пересоздаётся флагом `--voice`).
Зависимости: `pip install piper-tts numpy`, Node + Playwright, ffmpeg.
Шрифты Montserrat и Rubik — OFL (лицензии в `fonts/`).
